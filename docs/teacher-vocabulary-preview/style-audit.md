## 凍結視覺契約

- **媒材與線條：** 童趣但不幼稚的手繪數位卡通。深灰褐色、略有粗細變化的圓角外輪廓，內部細節極少。
- **色彩：** 明亮但非螢光。以暖膚色、朱橙、草綠、湖藍、粉紅為主，搭配深色線條；不用漸層炫光。
- **背景與構圖：** 預設透明背景，正方形 1:1。單一概念置中並保留邊界，必要時最多一個支援情境。不得有裝飾性背景、投影、邊框或密集物件。
- **簡化：** 人物為圓頭、簡化五官與短肢體；物件為清楚剪影與少量色塊。動詞畫出可辨識的一個動作，不以文字補充答案。
- **匯出：** 最終 preview derivative 為 512px 以內的 WebP，保留透明 alpha。來源教師圖的既有尺寸不被覆寫或改動。
- **禁止：** 任意文字、漢字、拼音、英文字、logo、品牌、浮水印、徽章、題目答案、寫實照片、仿製單一參考圖、政治符號與文化刻板印象。

## 一致性審查程序

1. 先以本文件的共通提示詞產一張，並檢查主體、透明角落、無文字與無浮水印。
2. 前 3 至 5 張以參考集合比較：輪廓粗度、簡化度、飽和度、留白與主體比例。
3. 每 25 張再抽樣至少 3 張。只可調整共通提示詞的風格措辭，不能改動已凍結的 source row、圖像狀態或 provenance。
4. 任一張出現文字、logo、錯誤概念、複雜背景或風格漂移時，拒絕該檔，增加 generation revision，保留拒絕原因於 generation manifest。
