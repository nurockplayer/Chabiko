# Chabiko 1.0 production-release acceptance

Production is [Chabiko](https://chabiko.pages.dev/), deployed from `main`. This snapshot was taken on 2026-11-28 JST. Live rows describe the responses served by Pages. Local checks use `main` at `888a275f557a0189c1351e01199e332c4ec9addb`, verified against GitHub at the start of the run. The live site did not expose a commit identifier, so the two observations are recorded separately. The 2026-11-28 JST production recheck covered TW-05, TW-06, DATA-02, DATA-04, and RES-02. GitHub deployment metadata could not identify the exact SHA served by Pages. The observed behavior confirms the changes from [#560](https://github.com/nurockplayer/Chabiko/pull/560), [#563](https://github.com/nurockplayer/Chabiko/pull/563), and [#564](https://github.com/nurockplayer/Chabiko/pull/564) are live.

A row passes when the stated check succeeds, fails when observed behavior contradicts it, and is unknown when evidence is missing or the check did not finish. Release requires a pass on each row marked **yes**. Re-run those rows on the release deployment. GitHub reports the milestone as open with 20 closed issues and zero open issues. [v1.0 MVP milestone](https://github.com/nurockplayer/Chabiko/milestone/1)

Browser checks use one headless Chromium session at a time, Playwright 1.61.1, a guest profile, a 375 × 812 viewport, and the production URL. HTTP checks inspect production responses directly. Use a fresh context for any check that changes storage, locale, network or theme. Local commands run from the repository root via `tachi-run -- <command>`. Scope follows [Static-first V1](../decisions/adr-0001-static-first-v1.md), [decision #522](https://github.com/nurockplayer/Chabiko/issues/522), [the lead decision log #535](https://github.com/nurockplayer/Chabiko/issues/535), and the [Daily Taiwan Chinese readiness contract](../strategy/daily-taiwan-chinese-readiness-map.md).

## Not in 1.0

- [#542](https://github.com/nurockplayer/Chabiko/issues/542): NFC-specific schema-validator regression test coverage. A local negative control rejected a voiced kana distractor canonically equivalent to the answer.
- [#547](https://github.com/nurockplayer/Chabiko/issues/547): the paid voice-comparison credential error was addressed by [#548](https://github.com/nurockplayer/Chabiko/pull/548). The paid audition is outside release acceptance. The local audio suite passed all 18 tests, including credential acquisition failure.
- [#549](https://github.com/nurockplayer/Chabiko/issues/549): concurrent key misses now share the in-flight refresh after [#551](https://github.com/nurockplayer/Chabiko/pull/551). The local Access suite passed all 23 tests, including the concurrent key-miss case. SEC-02 covers the live denied-access boundary.
- [#561](https://github.com/nurockplayer/Chabiko/issues/561): automated production CSP regression coverage and the Supabase-enabled variant. SEC-01 checks the deployed guest policy and runtime directly.
- [#526](https://github.com/nurockplayer/Chabiko/issues/526): teacher/Owner selection of a new Taiwan Mandarin voice and any paid generation remain separate from the layered-audio check.
- [#465](https://github.com/nurockplayer/Chabiko/issues/465), [#471](https://github.com/nurockplayer/Chabiko/issues/471) and [#473](https://github.com/nurockplayer/Chabiko/issues/473): Small Talk Lab prototype, pilot and convergence. Live roleplay remains in TW-04.
- [#33](https://github.com/nurockplayer/Chabiko/issues/33), [#338](https://github.com/nurockplayer/Chabiko/issues/338) and [#263](https://github.com/nurockplayer/Chabiko/issues/263): Unicode visual-similarity research, rubric and learner comparison browser.
- [#133](https://github.com/nurockplayer/Chabiko/issues/133): optional vocabulary artwork modernization. [#375](https://github.com/nurockplayer/Chabiko/issues/375): scored HSK level tests deferred in #522.
- Offline cold-start and reinstall support, cross-device sync, speech recognition and pronunciation scoring are outside the static-first V1 contract.
